# rotd_loots items

The loot tables give items by name. An item that does not exist in your item list is **skipped** and the server console prints "not in your item list". Add the ones you want; the rest simply never drop.

**QBCore / Qbox:** `qb-core/shared/items.lua`. **ox_inventory:** `data/items.lua`. **ESX:** the `items` table. **core_inventory** uses the framework item list.
