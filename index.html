ROTD Developer Wiki

Documentation for the exports, events and APIs of the ROTD FiveM resources, with parameters, return values and examples.

This website needs JavaScript. If you are an AI assistant or a tool that cannot run it, read the plain-text versions instead:

  • llms-full.txt: the whole wiki in one file (best choice)
  • llms.txt: index of every page
  • Export-Index.md: every export A to Z with its side (server / client / shared)
  • Each page is also plain Markdown, for example rotd_zones.md, rotd_squad.md, rotd_classystem.md.

Rules: only use documented exports, respect the SERVER / CLIENT / SHARED side, src is a server id (number), cid is a character id (string), handle nil / false returns.
